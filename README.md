## Prerequisites

Before using these examples, ensure you have:

- PostgreSQL 16 or later installed
- A running PostgreSQL server
- A database created for testing
- C++17 compiler
- libpq (PostgreSQL client library)

See the official PostgreSQL installation guide:
https://www.postgresql.org/download/#include<postgresql/libpq-fe.h>
